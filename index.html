Engine Architecture

Built for developers who value instant execution and zero ceremony.

GitSync removes manual staging, switching terminal windows, and token configurations. Everything happens automatically in a streamlined desktop environment.

Zero-Friction Realtime Sync

Debounced automated commit and push triggers on file save (customizable from 200ms to 3000ms). Background polling constantly checks for remote changes with automatic non-destructive fast-forward pulls.

Auto-commit debounce 600ms default

Embedded Monaco Editor

The exact editing engine that powers VS Code. Full IntelliSense, syntax tree analysis, side-by-side diff inspection against HEAD, code folding, multi-cursor editing, and an integrated script runner.

Core Engine Monaco v0.48.0

Multi-Engine AI Architecture

Freedom of choice: Built-in Smart Local Engine (offline, 0 setup), Google Gemini API (fast high-rate-limit free tier), Ollama Local (localhost:11434 with GPU acceleration), and OpenAI/Custom endpoints.

Supported Backends Gemini / Ollama / Local

GitHub Device Flow Auth

Never copy-paste fragile Personal Access Tokens (PATs) again. GitSync authenticates via standard GitHub RFC 8628 Device Authorization Flow directly in your default browser in under 5 seconds.

Protocol OAuth 2.0 Device Code

Native Windows Integration

System tray minification with live sync status indicators, Windows Action Center notifications on push/pull completion, dark mode Windows titlebar styling, and negligible standby RAM footprint.

Platform Win10 / Win11 x64

Deterministic Conflict Guard

If upstream changes conflict with local uncommitted work, GitSync halts automatic push, protects your working tree, and presents Monaco's visual side-by-side 3-way merge tool with one-click resolution.

Safety Guarantee Zero Unprompted Overwrites
Technical Deep Dive

Under the Hood: Architecture & Execution Pipeline

GitSync operates across an asynchronous multi-process architecture to guarantee editor responsiveness even while synchronizing large repositories.

01 / RENDERER Monaco Viewport

Keeps keystrokes fluid at 120 FPS. Fires atomic change signals via Electron ContextBridge.

IPC: onDidModelChange
02 / DEBOUNCE QUEUE Adaptive Timer

Aggregates rapid edits during active typing. Cancels pending triggers until typing pauses for >600ms.

Window: 600ms Debounce
03 / WORKER PROCESS Native Git Worker

Node.js child worker invokes libgit2 / system git binary directly. Index staging, tree hash, commit.

Thread: Isolated Subprocess
04 / REMOTE SYNC GitHub Push & Ack

Secure HTTPS / SSH push via OAuth Device token. Dispatches success event to system tray and UI status bar.
